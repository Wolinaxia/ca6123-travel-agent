# Notebooks

`demo.ipynb` is the notebook we submit. It has one section per stage and clear
markdown. Sections 0 (setup), 1 (Overview) and 3 (Reason) are written. The other
sections are placeholders that name their owner.

- **Locally:** open the notebook with the repo's `.venv` as the kernel (needs `.env`
  with your key).
- **In Colab:** upload the notebook and add `GOOGLE_API_KEY` to Secrets. The setup
  cell clones the repo and installs the requirements.

Add your section in place, run the whole notebook top to bottom before you commit,
and make sure no output shows a key. Rename the file to include our group number
before submission.
